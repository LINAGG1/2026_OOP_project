# 2026_OOP_project: 도서관 관리 시스템

Java Swing과 MVC(Model-View-Controller) 디자인 패턴을 활용하여 구현한 도서관 관리 시스템입니다.

사용자는 회원가입 및 로그인을 통해 도서관 서비스를 이용할 수 있으며,
도서 검색, 도서 대출, 도서 반납 및 개인 대여 현황을 확인할 수 있습니다.

관리자는 별도의 관리자 기능을 통해 도서를 등록하거나 삭제할 수 있습니다.

---

## 프로젝트 소개

### 프로젝트 목적

Java의 객체지향 프로그래밍과 MVC 디자인 패턴을 활용하여
도서관에서 이루어지는 기본적인 도서 관리 및 대출 업무를 구현하였습니다.

Model, View, Controller의 역할을 분리하여 각 기능의 책임을 명확하게 구성하고,
객체 간의 관계와 데이터 흐름을 이해하는 것을 목표로 하였습니다.

---

## 사용자

### 일반 사용자

일반 사용자는 다음과 같은 기능을 이용할 수 있습니다.

- 회원가입
- 로그인
- 도서 검색
- 도서 대출
- 도서 반납
- 현재 대여 중인 도서 확인

### 관리자

관리자는 다음과 같은 도서 관리 기능을 이용할 수 있습니다.

- 도서 등록
- 전체 도서 목록 확인
- 도서 삭제

---

## 주요 기능

### 회원가입 및 로그인

- 사용자 ID와 비밀번호를 이용한 로그인
- 사용자 이름 및 정보 관리
- 관리자와 일반 사용자 권한 구분
- 회원가입 시 필수 입력값 검증

### 도서 검색

- 도서 제목을 기준으로 도서 검색
- 검색 결과를 JTable을 통해 화면에 표시
- 도서 ID, 도서명, 저자, 대여 가능 여부 확인

### 도서 대출

- 검색 결과에서 원하는 도서를 선택하여 대출 신청
- 이미 대여 중인 도서는 대출할 수 없도록 처리
- 대출 성공 시 도서의 대여 상태 변경
- 사용자의 대여 목록에 해당 도서 추가

### 도서 반납

- 마이페이지에서 현재 대여 중인 도서 확인
- 반납할 도서를 선택하여 반납
- 반납 성공 시 도서의 대여 상태 변경
- 사용자의 대여 목록에서 해당 도서 제거

### 관리자 도서 관리

- 새로운 도서 등록
- 등록된 도서 목록 확인
- 선택한 도서 삭제
- 도서 ID, 도서명, 저자 등의 정보 관리

## MVC 구조

본 프로젝트는 MVC(Model-View-Controller) 디자인 패턴을 기반으로 구성하였습니다.

```text
                    ┌──────────────┐
                    │     View     │
                    │  사용자 화면  │
                    └──────┬───────┘
                           │
                           ↓
                    ┌──────────────┐
                    │ Controller   │
                    │ 요청 처리 및  │
                    │ Model 연결   │
                    └──────┬───────┘
                           │
                           ↓
                    ┌──────────────┐
                    │    Model     │
                    │ 데이터 관리 및 │
                    │ 기능 처리     │
                    └──────────────┘
